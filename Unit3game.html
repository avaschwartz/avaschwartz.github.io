Final Code: This code allows the Arduino to detect when one of the four buttons is pressed. ```cpp const int buttons[] = {2, 3, 4, 5}; void setup() { Serial.begin(115200); for (int i = 0; i < 4; i++) { pinMode(buttons[i], INPUT_PULLUP); } } void loop() { for (int i = 0; i < 4; i++) { if (digitalRead(buttons[i]) == LOW) { Serial.print("1"); } else { Serial.print("0"); } } Serial.println(); delay(5); } ```

Challenges:

During this project, the main challenge I faced was connecting the four buttons to the Arduino Uno. One challenge was making sure each button was connected to the correct digital pin and GND. Another challenge was getting the Arduino and Python program to communicate through serial communication. I also had to make sure each button sent the correct keyboard input (D, F, J, and K) so the Piano Tiles game could recognize it.

Final Product

My final product is a four-button Piano Tiles controller made using an Arduino Uno, a breadboard, four push buttons, and jumper wires. Each button represents a different lane in the game. When I press a physical button, the Arduino detects the signal and sends the information to my computer. The Python program then converts that signal into a keyboard input, allowing me to play Piano Tiles using my custom-built controller. But the controller still does not work.
