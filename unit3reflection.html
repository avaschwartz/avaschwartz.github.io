Unit 3: One Shot Game

Soda Pop Tiles

Game Link

Play Soda Pop Tiles

Goal

My goal was to modify my original Piano Tiles game so that it would play a specific tune instead of making random notes. I wanted to make the game more interesting and musical while keeping the original gameplay and keyboard controls.

Process:

Orginal prompt: Can you make me a downloadable Piano Tiles game that I can play using my keyboard? Make it colorful and interactive, with falling tiles, a score counter, sound effects, and restart controls. Then change it so the tiles play a Soda Pop-inspired tune instead of random notes.

First, I started with my existing Piano Tiles game, which was made using HTML, CSS, and JavaScript. The game already had falling tiles, a score counter, sound effects, and keyboard controls (A, S, D, and F).

Next, I looked at how the game created tiles and played sounds. Originally, the tiles appeared in random lines, so the notes were also random. I changed the code so that the tiles would follow a set order instead. Each lane represented a different musical note, and pressing the correct key played that note. But I still kept the original design, scoring system, restart button, and sound toggle so the game would still be easy to play.

Final Prompt:Make me a downloadable Piano Tiles game that plays a Soda Pop-inspired tune and can be controlled with my keyboard.

Challenges:

One challenge was changing the tile system from random generation to a fixed sequence. I needed to make sure the game reset the sequence when a new game started and the tune could continue from the middle when restarting.

Another important part was connecting the correct keyboard controls to the notes. I kept the four controls A, S, D, and F, with each key representing one line.

Final Result:

I created an updated version of Piano Tiles called Soda Pop Tiles. The game uses a repeating sequence of notes instead of random notes. Players can use the keyboard or click the tiles to play, earn points, and try to beat their best score.

What I Learned:

This project helped me understand how JavaScript can control both gameplay and sound. I learned that changing a small part of the code, such as how tiles are generated, can change the entire experience of a game. I also learned how programming can combine music, timing, and interaction to make a project more engaging.

Next Steps:

If I continued working on this project, I would improve the timing between the notes, add difficulty levels, and make the melody more recognizable. I would also want to try to use the app “Devin” to organize my code better and get help on how to fix it from the built-in AI agent.
